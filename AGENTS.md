# HeatShift project instructions

Read README.md, docs/BUILD_PLAN.md and the relevant GitHub issue before implementation. Keep issue status consistent with demonstrated behavior.

All changes to `main` must go through a pull request. This applies to administrators too. Work on a short-lived branch; never disable branch protection or force-push `main` to deliver a change. Review the diff and applicable checks before merging. Independent reviewer approval is currently optional.

The user authorized the project foundation, plan and public GitHub setup. Follow subsequent implementation instructions and preserve existing work. Do not infer that a planned feature is complete.

Use Gemma 4 through the Gemini API for meaningful application inference. Keep keys server-side. Use deterministic code for schedule validity and comparison metrics. Never substitute invented model responses or stale fixtures for a claimed live integration.

Preserve all three intended competition requirements and the public open-source repository. Keep development-tool attribution out of the product and team messages. Track organizer-required disclosures separately in docs/SUBMISSION.md and do not falsely mark eligibility or submission complete.

Teammates provide expertise and steering. Do not assign them software implementation or make their input a prerequisite. Team progress messages are authorized in the designated hackathon WhatsApp group; post only verified, concise milestones or blockers and avoid duplicate updates. Do not publish private chat content or contact details in this repository.

Keep scope to one crew, one location, one day and four tasks until the core flow is verified. Preserve paid shift time, task durations, breaks, dependencies and appointments. Treat no-improvement and infeasibility as valid outcomes.

Use focused tests for schedule constraints and forecast/time normalization. Verify the deployed input-to-result flow and fresh-clone setup before claiming a working release. Update documentation and example configuration when behavior changes.
