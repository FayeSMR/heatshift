Runtime evidence and the current demo URL are in [VERIFICATION.md](VERIFICATION.md). These implementation checks do not establish organizer acceptance or complete the entry.

## Two-minute demonstration

1. **0:00–0:20:** Introduce one Miami landscaping supervisor and tomorrow's work order.
2. **0:20–0:45:** Show Gemma extracting tasks, then confirm the constraints.
3. **0:45–1:20:** Compare timelines against the sourced forecast; explain the computed difference without overstating health benefits.
4. **1:20–1:45:** Show the crew briefing and switch language.
5. **1:45–2:00:** Show the public repository and the verified Gemma integration.

Allow one minute for questions. Record a backup demonstration while the working build is available.

## Judging

The on-site slide supplied by the team scores each criterion from 1–10: community impact 30%, working build 25%, AI/data 20%, originality/craft 15%, and demo clarity 10%. Its scoring scale supersedes the earlier written guide. Prioritize the specific user, a live core flow, and verifiable AI/data work.
